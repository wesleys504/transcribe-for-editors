Transcribe update: sequence XML export, markers, timecode fix, ClipCleaner colors, faster on Intel

Copy these into your transcribe-for-editors folder and replace when asked.

NEW
  nle.py              Premiere/Resolve XML (sequences and markers)

REPLACE
  app.py              new export endpoints, done sound
  projects.py         "Sequence" export from paper edits
  transcribe.py       timecode fix, auto model per Mac, Intel speedups, stage timings in the log
  ui/index.html       new buttons, settings, ClipCleaner colors
  install.command     Intel installs the fast English model
  README.md           docs for the new features

Then commit and push (GitHub Desktop or Terminal):
  git checkout -b radio-cut-xml
  git add -A
  git commit -m "Sequence XML export, markers, timecode fix, ClipCleaner colors, Intel speedups"
  git push -u origin radio-cut-xml
and open a pull request on GitHub.

To use it on a Mac that already has Transcribe: run install.command again (updates take about a minute).
